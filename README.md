# Moiz ud Din — AI Engineer Portfolio

A responsive static portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve this folder with a local static file server.

## Deploy to Vercel

This site has no build step or runtime dependencies. To deploy with Vercel:

1. Import `moizpirzada1/moiz-ud-din-portfolio` into Vercel.
2. Select **Other** as the framework preset if Vercel does not detect it automatically.
3. Leave the build command empty and set the output directory to `.`.
4. Deploy.

The site entry point is `index.html` at the project root. Vercel can also deploy updates automatically after the GitHub repository is connected.

## Personalize

Update the page content and contact details in `index.html`. Project descriptions, repository links, demo links, categories, and generated SVG thumbnails are maintained together in the `projects` array in `script.js`. Adjust the presentation in `styles.css` and interactive navigation/project filters in `script.js`.
